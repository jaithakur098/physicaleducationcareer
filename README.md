# Physical Education Career — Starter Template

A single-page, fully responsive, SEO-ready starter.

## Files
- `index.html` — single-page site (Home / Courses / About / Reviews / Contact)
- `style.css` — global stylesheet (dark blue + gold + red theme)
- `script.js` — mobile menu, scroll animations, animated counters, lead form
- `images/` — drop site photographs here (see images/README.txt)
- `assets/` — drop brand assets here: logo, favicon, og-image (see assets/README.txt)

## Run locally
Just open `index.html` in a browser. No build step needed.

## Deploy
- **GitHub Pages**: push to a repo, enable Pages from `main` branch root.
- **Netlify**: drag this folder onto https://app.netlify.com/drop
- **Vercel**: import the folder, framework preset = "Other".
