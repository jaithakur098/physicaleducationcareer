CBSE Physical Education resources

CBSE Physical Education is a theory-plus-practical subject. Marks are lost when students memorise headings without being able to draw a fixture, name a committee, or explain a test protocol. Use this page as a map, then open the unit you need.

Confirm the current unit list from the CBSE curriculum document for your session. Titles below match the unit pages published on this site.

How to study one unit in 90 minutes

  1. Read the unit page once without highlighting.
  2. Write five definitions in your own words (not copied sentences).
  3. Do the MCQs or the chapter test if one exists.
  4. Answer one long question with headings, examples and a concluding line.
  5. Note one practical link (how this unit appears in the file or viva).

Where Class 11 and 12 overlap

Anatomy, fitness components, yoga and training methods appear in both classes. If you are in Class 12, do not skip a weak Class 11 unit — the board will still use those terms. If you are in Class 11, write answers in the same numbered format you will need next year.

Chapter tests that ask for a student login are practice tools, not official board papers.
