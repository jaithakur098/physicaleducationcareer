Practical and viva resources

The PE practical is not a last-week photocopy job. Internal marks usually combine a record file, demonstration of skills or yoga, a fitness test, and a viva. External examiners look for a file that matches the student who is standing in front of them.

What this category covers

  • Building the practical file, section by section
  • Viva questions that follow from the file
  • Fitness tests you can actually administer in a period
  • Class 12 test and measurement unit (protocols you will be asked to name)
  • Event management unit (fixtures you may have to draw)

Minimum evidence in a file

SectionWhat to include
Personal detailsName, class, school, session — same spelling as the admit card.
Game / activityHistory in 8–10 lines, fundamental skills, labelled court/field, rules in your words, terminologies.
Athletics / yogaEvents or asanas practised this year with points of technique, not a downloaded collage.
Fitness testName of test, purpose, equipment, procedure, scoring, your recorded score with date.
PhotographsYou performing, not a stock image of a stadium.

Week-before-practical checklist

  1. File photos show you, dated, with the same uniform as the viva day if the school requires it.
  2. You can demonstrate one skill and name the test protocol you recorded.
  3. You can draw the court/field of your game from memory — viva often starts there.

PDFs that exist: downloads. There is no “board approved template” file on this site; your school’s circular wins.
