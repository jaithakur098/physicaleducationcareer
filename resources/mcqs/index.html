MCQ practice for Physical Education

MCQs in PE punish vague reading. “Seeding” is not the same as a “bye”. “Intramural” is not “extramural”. Use tests to find those gaps, not to farm a high score you cannot explain.

A method that works

  1. Attempt a chapter test in one sitting without notes.
  2. Write every wrong item in a notebook: the concept, not the option letter.
  3. Open the matching unit page and rewrite the definition in one sentence.
  4. Re-attempt only the error list after 48 hours.

Some tests require a student login so scores can be stored. Those pages are practice tools and are not submitted to CBSE.

Where the questions live

  • Unit pages such as Class 12 Unit 3 include on-page MCQs.
  • Chapter test pages (for example Class 11 Chapter 1–2 tests and Class 12 Chapter 1–2 tests) are linked from cbse.html.
  • A larger bank is used by the test engine under tests/; that engine is for logged-in practice, not for search engines.

Example of an MCQ trap

“Number of matches in knock-out of 13 teams” is 12 (N − 1), not 13. If you miss that, open Unit 1 and redraw a 13-team fixture once. Then return to tests.

After MCQs, switch to previous papers so you can write 3-mark and 5-mark answers.
