Class 11 Physical Education — papers and practice

This page is a practice map, not a locker of official CBSE PDFs for every year. Class 11 PE is usually 70 marks theory and 30 marks practical. The syllabus on this site is organised as ten units. Confirm unit titles against the CBSE curriculum PDF for your session.

There is no “Coming Soon” subject grid here. English, Physics and other subjects are not hosted on this PE site. For PE, start with unit notes, then timed writing, then the Class 12 papers later.

Who this hub is for

  • Class 11 students building the foundation that Class 12 will reuse (anatomy, fitness, training, yoga).
  • Teachers who want a unit order for tests, not a dump of unmarked files.

What you should verify

Question papers belong to CBSE. Any paper you download elsewhere should be checked against the current sample paper and marking scheme on cbse.gov.in / cbseacademic.nic.in. This site’s contribution is notes, MCQs and how to mark answers.

How to use the unit notes as if they were papers

  1. Revise one unit page.
  2. Write five 1-mark definitions from memory.
  3. Write one 5-mark answer with a diagram where the unit allows it.
  4. Attempt on-page MCQs or the chapter test linked from cbse.html.
